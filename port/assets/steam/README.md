# Steam artwork

The pictures `tools/steam_art.py` gives the OpenCE shortcut in Steam:
`portrait.png`, `wide.png`, `hero.png` and `logo.png`.

They were posted on [SteamGridDB](https://www.steamgriddb.com) by
[NFrong1](https://www.steamgriddb.com/profile/76561198067794800). Thank you to
them and to SteamGridDB, which hosts community artwork for game libraries.

The pictures show artwork of Halo: Combat Evolved, which belongs to Microsoft
and 343 Industries. They are not part of the game files and no package ships
them; the script copies them to Steam's own `grid` folder on the computer that
runs it.
